# Contributing to HoopRise

Install Node.js 20+, then run:

```powershell
npm install
npm run typecheck
npm run dev
```

Keep HoopRise local-first and offline-capable. Do not add Firebase credentials, private keys, or hard-coded secrets. Put shared business logic in `shared/` when desktop and Android both use it. Preserve touch-friendly layouts and keyboard accessibility. Run `npm run typecheck` before opening a pull request.

Use original UI, icons, copy, and drill instructions. Player-inspired training must be described as publicly inspired unless reliable public information supports a stronger statement. Do not add NBA or team logos, player photos, copyrighted sounds, or copied game assets.
